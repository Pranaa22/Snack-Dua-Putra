KRIUKKITA — PATCH v3 (KASIR / MIDTRANS / DETAIL / PROMO / WARNA)
=============================================================
UNTUK: project Laravel 12 dan DB db_kriukkita YANG SUDAH ADA.
TIDAK PERLU membuat project atau database baru.
Paket ini melanjutkan KriukKita_Implementasi_Laravel12 + KriukKita_Patch_Kasir_Foto_v2.

WAJIB BACKUP DAHULU
- Backup C:\laragon\www\kriukkita
- HeidiSQL: export database db_kriukkita ke .sql
- JANGAN jalankan php artisan migrate:fresh / migrate:refresh.

CARA PASANG
1. Tutup server Laravel (Ctrl+C pada terminal php artisan serve).
2. Ekstrak ZIP di Downloads terlebih dahulu.
3. Copy isi folder app, database, public, resources, routes ke:
   C:\laragon\www\kriukkita\
   Pilih Replace Files jika diminta.
   JANGAN menaruhnya sebagai folder KriukKita_Patch_v3 di dalam project.
   .env dan vendor tidak perlu ditimpa.
4. Pastikan MySQL Laragon aktif. Di terminal folder project:
   cd C:\laragon\www\kriukkita
   php artisan optimize:clear
   php artisan migrate
   php artisan db:seed --class=KriukPromoSeeder
   php artisan optimize:clear
   php artisan serve
5. Buka http://127.0.0.1:8000 lalu Ctrl+F5.
6. Periksa Kasir Tunai, Admin > Kode Promo, Admin > Produk & Stok,
   dan Detail Produk di katalog.

YANG DIPERBAIKI
- Kasir: orders.courier diperbesar dari panjang lama ke varchar(50).
  Teks "Ambil di toko" sekarang muat; pelanggan kasir tak wajib mengisi alamat.
- Promo: tabel promotions dan orders.promo_code, API validasi dan diskon
  server-side. Admin > Kode Promo: tambah/edit/nonaktifkan/hapus.
  Seeder KriukPromoSeeder hanya menambahkan UMKMLOKAL (Rp5.000) apabila belum ada;
  kode yang sudah dibuat admin TIDAK ditimpa.
- Detail: tautan "Buka halaman detail lengkap" di popup dihapus.
- Kerenyahan/Pedas: judul singkat dan meter rata kiri/kanan.
- Warna kemasan: pratinjau SVG langsung, Terapkan Warna Ini, Reset Warna.
  Warna baru BENAR-BENAR tersimpan setelah klik "Simpan Produk".
  Bila produk menggunakan foto asli, foto tetap ditampilkan sebagai visual
  utama; pemilihan warna berpengaruh pada ilustrasi SVG cadangan.

PENTING: AKTIFKAN MIDTRANS SANDBOX
Pesan "Pembayaran online belum aktif" bukan masalah HTML. Kunci Midtrans
masih kosong/tidak terbaca. Website TIDAK bisa membuat API key sendiri.
- Login https://dashboard.midtrans.com/login
- Pilih lingkungan SANDBOX (bukan Production).
- Masuk SETTINGS > ACCESS KEYS.
- Salin dua kunci Sandbox ke .env pada ROOT project:
  MIDTRANS_SERVER_KEY=ISI_SERVER_KEY_SANDBOX_KAMU
  MIDTRANS_CLIENT_KEY=ISI_CLIENT_KEY_SANDBOX_KAMU
  MIDTRANS_IS_PRODUCTION=false
- Jalankan: php artisan optimize:clear
- Refresh checkout dan coba transaksi di lingkungan SANDBOX.
- Pastikan composer package midtrans/midtrans-php sudah terpasang.
- Server Key RAHASIA: jangan dibagikan ke chat, screenshot, repo publik.
- Pada localhost, webhook Midtrans tidak bisa masuk langsung. Gunakan
  halaman status pesanan dan/atau php artisan schedule:work untuk cek ulang.
- Integrasi ini BELUM diverifikasi menggunakan kunci merchant kamu.
